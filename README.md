# telecom-analysis
Análisis de clientes de ConnectaTel con Python: limpieza de datos, segmentación y recomendaciones de negocio.
# Análisis de Clientes - ConnectaTel

## Descripción del proyecto
En este proyecto analicé los datos de los clientes de ConnectaTel para conocer sus hábitos de consumo, identificar patrones de uso y proponer mejoras en los planes de telefonía.

## Objetivo
Analizar la información de los usuarios, sus llamadas y mensajes para identificar diferentes segmentos de clientes y encontrar oportunidades de mejora para el negocio.

## Datasets utilizados
- `plans.csv`: información de los planes de telefonía.
- `users_latam.csv`: información de los usuarios.
- `usage.csv`: registros de llamadas y mensajes.

## Herramientas utilizadas
- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

## Etapas del análisis
1. Exploración inicial de los datos.
2. Identificación y limpieza de valores faltantes e incorrectos.
3. Análisis exploratorio de las edades, llamadas y mensajes.
4. Identificación de valores atípicos mediante el método IQR.
5. Segmentación de clientes por edad y nivel de uso.
6. Elaboración de conclusiones y recomendaciones para el negocio.

## Principales resultados
- El grupo de uso medio es el más frecuente entre los clientes.
- Los adultos representan el grupo de edad más numeroso.
- Se identificaron usuarios con niveles de consumo superiores a los habituales.
- Los clientes presentan diferentes necesidades según su nivel de uso.

## Recomendaciones
- Mejorar los planes dirigidos a usuarios de consumo medio.
- Ofrecer opciones económicas para clientes de bajo uso.
- Evaluar planes con más minutos y mensajes para usuarios de alto consumo.

## Cómo ejecutar el proyecto
1. Descargar el notebook `.ipynb` y los datasets autorizados.
2. Abrir el notebook en Jupyter Notebook.
3. Instalar las librerías necesarias: Pandas, Seaborn y Matplotlib.
4. Ajustar las rutas de los archivos CSV según el entorno.
5. Ejecutar las celdas en orden para reproducir el análisis.

**Nota:** Para reproducir el análisis es necesario tener acceso a los datasets originales.
